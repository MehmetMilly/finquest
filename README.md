# FinQuest 2036 · فِن كويست

نموذج أولي عربي أولاً للتثقيف المالي، طُوّر للمشاركة في هاكاثون **AMAD 2026**.

> جرّب القرار قبل ما تلتزم، وقابل النسخة اللي راح تعيش أثره.

**التجربة المباشرة:** [finquest-app-mu.vercel.app](https://finquest-app-mu.vercel.app/)

## عن المشروع

يحوّل FinQuest قرار تمويل سيارة إلى تجربة تفاعلية كاملة. يبدأ المستخدم بملف شخصي مختصر أو بملف سارة التجريبي، ثم يعدّل عرض السيارة ويقارن ثلاثة مسارات مستقبلية محسوبة على مدى 120 شهراً. بعد ذلك يشرح له رفيقه المستقبلي «فِي» أثر القرار بالعربية، ويحوّل الفكرة إلى مهمة مالية صغيرة قابلة للمتابعة.

الهدف ليس التنبؤ بالسوق أو تقديم استشارة مالية، بل جعل تكلفة الالتزام الكبير مفهومة قبل اتخاذه.

## ما تم تنفيذه

- تسجيل مختصر للبيانات الشخصية مع هدف اختياري، أو تحميل ملف سارة التجريبي بضغطة واحدة.
- حفظ محلي مُرقّى للملف الشخصي، وقرار السيارة، والمهام، والخبرة (XP)، والاستمرارية، والمستوى، والشارات.
- محرك محاكاة حتمي لمدة 120 شهراً يشمل التمويل، الدفعة الأخيرة، خدمة الدين، التضخم، النمو، العائد المركب، انخفاض قيمة السيارة، السيولة، العجز، وتأخر الهدف والتكلفة البديلة.
- مقارنة ثلاثة مسارات مستقبلية، مع تحليلات حساسية تبدأ دائماً من خط الأساس.
- شرح عربي grounded عبر نقطة خادم اختيارية، مع حدود صارمة للأرقام والنصائح، وتخزين مؤقت، وتحديد للطلبات، ومهلة زمنية، وبديل محلي كامل عند عدم توفر النموذج.
- شخصية مستقبلية محلية متحركة بصيغة SVG، بمزاج متسق، وتسميات وصول، ودعم لتقليل الحركة.
- تحرير آمن بلوحة المفاتيح لسعر السيارة والدفعة الأولى والدفعة الأخيرة، مع نوافذ حوار تدعم حبس التركيز واستعادته.

## التشغيل محلياً

يتطلب المشروع Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

تعمل التجربة الأساسية بالكامل من دون مفتاح API. لتجربة نقطة Vercel محلياً، استخدم بيئة Vercel مرتبطة بالمشروع وضع المتغير السري على الخادم فقط:

```bash
OPENROUTER_API_KEY=... npx vercel dev
```

لا تستخدم متغيراً يبدأ بـ `VITE_` لهذا المفتاح. ملف `.env.example` يحتوي على قيمة فارغة للتوضيح فقط.

## التحقق

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

الاختبارات لا تنفق أي أرصدة API؛ فهي تحاكي مزود النموذج. آخر تحقق محلي موثق: فحص الأنواع، وLint بلا تحذيرات، و46 اختباراً ناجحاً، وبناء إنتاجي ناجح.

## مسار العرض السريع

1. حمّل سارة من شاشة البداية.
2. افتح **القرارات ← شراء سيارة** وعدّل العرض.
3. قارن المسارات الثلاثة وجرب إعداد حساسية واحداً.
4. اسأل «فِي» سؤالاً مقترحاً ولاحظ وسم مصدر الشرح المحلي أو الذكاء الاصطناعي.
5. ابدأ مهمة مالية وتابعها ثم سجّل إكمالها لترى الخبرة والشارات.
6. افتح الافتراضات والحساب، حدّث الصفحة للتأكد من الحفظ المحلي، ثم جرّب إعادة الضبط.

## البنية التقنية

- `src/domain/` — محرك التمويل الحتمي، الحساسية، وانتقالات المهام.
- `src/state/` — حالة التطبيق والملف والمهام مع ترقية للحفظ المحلي.
- `src/screens/` — شاشات البداية، المنزل، القرار، المستقبل، المهام، والحساب.
- `src/avatar/` — شخصية المستقبل المحلية بصيغة SVG.
- `src/services/narrative.ts` — حقائق الشرح، البديل المحلي، وطبقة الطلب والتخزين المؤقت.
- `api/explain.ts` — حد الخادم بين Vercel وOpenRouter.
- `src/styles/` — إيقاع عربي، ومتغيرات الواجهة، وتنسيقات متجاوبة.

التفاصيل الكاملة للحدود بين الأجزاء موجودة في [ARCHITECTURE.md](./ARCHITECTURE.md).

## النموذج والافتراضات

يعرض النموذج الافتراضي الفترة 2026–2036 باستخدام افتراضات تعليمية واضحة، منها: نمو راتب سنوي 3.5%، تضخم 2.5%، عائد استثماري 6.5%، عائد نقدي 2%، ومعدل تمويل فعلي توضيحي 6.2%. الالتزام الشهري المدخل يُستخدم كتقريب تعليمي واضح لمدة 12 شهراً.

هذه ليست بيانات SAIBOR أو TASI مباشرة، ولا شروط منتج بنكي، ولا معايير موافقة، ولا توقعات سوقية. كل رقم مالي يُحسب أولاً داخل `src/domain/simulationEngine.ts`؛ ودور النموذج اللغوي، عند توفره، هو شرح الحقائق المحسوبة فقط.

## الحدود بوضوح

- لا توجد مصادقة، أو قاعدة بيانات ملفات شخصية، أو بيانات مصرفية حقيقية، أو Open Banking، أو تحويل أموال، أو شراكة مصرفية رسمية.
- بيانات المستخدم الشخصية محفوظة في متصفح الجهاز محلياً، وليست تخزيناً مالياً إنتاجياً.
- تقدم المهام وإكمالها مُدخلان من المستخدم ويعتمدان على التصريح الذاتي.
- المحرك تعليمي، وليس نموذج قدرة ائتمانية أو استثمار أو ضرائب أو قانون معتمداً.
- المسارات المستقبلية سيناريوهات توضيحية وليست تنبؤات أو ضمانات.
- لا ندّعي نتائج اختبار مستخدمين؛ خطة الاختبار موجودة في [USER_TEST_PLAN.md](./USER_TEST_PLAN.md).

FinQuest تجربة تعليمية وليست نصيحة مالية أو استثمارية أو ائتمانية أو قانونية أو ضريبية.

## صلة المشروع بـ AMAD 2026

يجمع النموذج بين التثقيف المالي، والتحفيز بالألعاب، وشرح عربي مضبوط بالذكاء الاصطناعي، وتحليل السيناريوهات، وتجربة استخدام عربية متجاوبة. وهو يركّز عمداً على رحلة قرار واحدة عميقة وقابلة للقياس بدلاً من ادّعاء بناء منصة مالية عامة ببيانات سوق حية خلال الهاكاثون.
